# Excel Data Analytics Practice Workbook

This workbook contains fictional practice datasets and formula-driven examples for Excel data analysis. It includes sales math functions, payroll logic, text cleaning, attendance tracking, hospital and retail dashboards, customer data cleaning, pharmacy inventory, and bookstore inventory.

## Files

- `Data_Analytics_Practice_Workbook.xlsx`: workbook with source tables, formulas, dashboards, validation lists, conditional formatting, and a dashboard checklist.
- `Analytics_Dashboard_Summaries.pdf`: printable payroll and dashboard summary pages.

## Key workbook sections

- Sales totals with SUM, AVERAGE, MAX, MIN, and COUNT.
- Payroll formulas using IF, AND, and OR, with Naira currency formatting.
- Text cleanup using PROPER, TRIM, &, UPPER, LOWER, and LEN.
- Attendance data with TODAY, DATEDIF, dropdown validation, and conditional alerts.
- Michael Hospital and retail dashboards with KPIs, charts, findings, and recommendations.
- Pharmacy and bookstore lookup exercises using VLOOKUP and INDEX/MATCH. The XLOOKUP example is provided as text because older Excel versions cannot calculate it.
- Michael Electronics customer-cleaning exercise with raw and cleaned fields.

The formulas use legacy-compatible alternatives for CONCAT and XLOOKUP. All records are synthetic. Native PivotTables, PivotCharts, slicers, and Timeline controls remain manual Excel tasks; see the Practice Checklist sheet.
